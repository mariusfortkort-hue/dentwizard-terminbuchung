# Dent Wizard Terminbuchung

Statische Netlify-Website für Spotrepair-Terminanfragen.

## Veröffentlichung

1. Alle Dateien in dieses GitHub-Repository hochladen.
2. In Netlify: **Add new project → Import an existing project → GitHub**.
3. Repository `dentwizard-terminbuchung` auswählen.
4. Build command leer lassen, Publish directory `.` eintragen.
5. Deploy starten.

## Formulare

Das Formular verwendet Netlify Forms. Nach dem ersten Deploy erscheint es im Netlify-Bereich **Forms**. Dort können E-Mail-Benachrichtigungen eingerichtet werden.

## Hinweis

Die Seite nimmt Terminanfragen entgegen. Sie verhindert noch keine Doppelbuchungen und synchronisiert noch nicht automatisch mit Google Calendar. Das folgt in einem nächsten Ausbauschritt mit Datenbank/Serverfunktion.
